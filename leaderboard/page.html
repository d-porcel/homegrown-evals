Benchmark version $version. Only runs made with the current brief, style guide, cases, rubric, checks, scoring code and Inspect version are ranked, so every score comes from the same test.

$name is the average of $grade_list, where correct = 1, partial = 0.5 and incorrect = 0. Each judge's runs are ranked in their own table, since scores from different judges can't be compared. The line behind each score shows its 95% range: with a different set of similar cases, the score could land anywhere along it, so models whose ranges overlap a lot are hard to tell apart. Both costs cover the tested model's replies only, at the prices in prices.yaml: per 1,000 replies, to compare models, and for the whole run.
